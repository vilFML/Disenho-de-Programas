# Repositorio
Este repositorio contiene un proyecto vigente y en trabajo activo, del semestre Primavera 2026 de CC3002 - Metodologías de Diseño y Programación de la Facultad de Ciencias Físicas y Matemáticas de la Universidad de Chile.

---

El proyecto consiste en programas interconectados para diseñar un sistema de bajo acoplamiento y escalable a largo plazo.
Se utilizan metodologías como:
- Programación Orientada a Objetos.
- Encapsulación.
- Visibilidad.
- Programación TDD.
